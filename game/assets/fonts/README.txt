Selected type pairing: Bree Serif Regular headings and Nunito weight 600 body text.
Original files from https://github.com/google/fonts/tree/main/ofl/breeserif
and https://github.com/google/fonts/tree/main/ofl/nunito .
Both font families are redistributed with their complete SIL Open Font Licenses.
Godot FontVariation selects the Nunito wght axis using OpenType tag 2003265652.
No system font dependency or internet connection is required at runtime.
