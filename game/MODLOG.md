# Poppy asset integration

Existing scout-draw PNG uses an alpha 4x2 directional atlas; the draw code trims each cell and fixes the feet at player +16, drawing 56-pixel-tall figures with brown contours and painted colors. Existing scout-release uses the same format. Poppy uses a 1280x1280 RGBA PNG, four 640x640 cells in a 2x2 layout: front ready, front step/release, rear ready, rear step/release. Each cell is trimmed at load. Mirroring covers left-facing directions. Soft alpha and generated mipmaps preserve small-screen edges. No source image editing or recoloring is performed.

Generated with built-in imagegen from the approved left-hand Poppy concept. Prompt: game sprite sheet derived only from Poppy the gardener; transparent background; exactly two columns and two rows, four full-body sprites, same scale, centered; auburn short braids, floppy straw hat with green ribbon, sage overalls, ivory shirt, terracotta boots, canvas seed pouch; clean brown outlines and simplified matte painted detail; three-quarter front/right ready with wooden crescent boomerang, front/right walking with open throwing hand, rear/right ready, rear/right walking with open throwing hand; no labels, shadows, other characters or background. Feet share a baseline within each cell.

Real Godot captures of selection and combat inspected. Mipmaps enabled after the initial render showed aliasing. Poppy balance and behavior tests live in tests/poppy_checks.gd and tests/poppy_balance.gd.


Poppy walking correction / v0.9.1-test, Android code 21
Walk no longer swaps between standing and throwing full-body poses. Existing art is rendered as two six-vertex leg strips and a separate torso, with a stable scale and hip/foot reference. Alternating knee/boot movement follows actual travel distance; idle or blocked movement plants both feet. Retreat reverses the stride. Attack release changes only the upper-body region. Three small textured draws; no new textures, particles, or simulation work. Front/rear ready/throw render inspected. Regression tests cover attack independence, opposite steps, backpedaling, and blocked movement. Skill-pool redesign remains a proposal in this release.


## Character kits and unified style / v0.10.0-test (Android code 22)

The accepted proposal is implemented as two exclusive nine-skill catalogs, three ranks each, five rank-two compatibility pairs per character, guided three-card offers and two rerolls per expedition. Definitions live in character_skills.json; skill_catalog.gd draws the new illustrations and exposes rank requirements and benefit text. run_skills.gd owns timed tools, traps, marks, catches and bounded secondary effects. No legacy shared stat upgrades are applied by a character skill choice.

New asset brief and provenance: built-in imagegen created scout-storybook.png using Poppy's atlas as the strict style/proportion reference and the earlier Scout atlas only for identity. Brief: soft warm brown contours, matte painted fabric, tousled brown hair, blue headband, rust-orange jacket, ivory shirt, charcoal shorts, cream socks, brown boots, backpack and wooden Y slingshot; four matching full-body front/rear ready/release poses, fixed scale and feet, transparent background, no labels or shadows. Generated source exec-126cdf14-c414-49bf-a594-57a62082d353.png. Runtime atlas: 1280x1280 RGBA, two columns/two rows of 640px cells, front faces right, rear faces left and is mirrored by the shared renderer. Soft alpha, mipmaps and linear filtering. Poppy retains its approved source art.

Skill icon brief: eighteen isolated soft painted cozy garden objects, warm brown outlines, matte natural colors, transparent, no text or tiles, three columns/six rows; first nine are Poppy's boomerang, pollen, mothball pouch, dew boot, bee, leaf fan, leaf shield, petals, roots; last nine are Scout's ricochet seeds, acorn decoy, twine stakes, marked leaf, seed pouch, slingshot boot, bark shield, counterseed and basket. Generated source exec-705088d5-bbbd-409d-9f34-59f1cc2a382a.png. Runtime atlas: 1024x1536 RGBA, explicit per-icon source bounds with padding against neighboring rows, soft alpha, mipmaps. No raster modification was required.

Both characters use character_art.gd: two six-vertex leg strips plus an independently drawn torso. Same travel-based gait, scale, bob, attack handling and roll transform, with atlas-specific anchors only. Camp, character selection, combat and result portraits use the matching art. The unused six old Scout atlases no longer load into runtime and are excluded from exports. ART_STYLE.md and AGENTS.md make this a permanent project rule.

Calibration: later XP thresholds changed to 12/26/44/66/92/120/150/180/210 so slower builds continue earning decisions. The cap stays level 10, with up to nine XP choices, two miniboss choices and final preparation. Counterseed and Quickdraw reward active dodges; seed/root/fan effects have enough damage to support Poppy's control builds. Boss attacks, warning and victory delay remain unchanged. Effects cap at 20 zones, 80 live player shots, 24 queued shots/pulses/rings; boss slows have resistance and never speed up or suppress attack warnings. Secondary blast kills cannot chain additional blasts.

Real Godot renders inspected: shared idle/walk/fire/retreat/rear/roll board; both choice menus and loadouts; both camp/result portraits; both combat tool kits. Regression checks cover all 18 skills, all 10 compatibility effects, first-use timers, nonstacking guard, no repeated petal collection, independent Quickdraw near-miss, bounded swarm effects, save-independent reset, touchscreen/controller selection and shared gait. Full chapter calibration and publication results are recorded in the release validation output.

Final Poppy tuning: throw interval 0.64 seconds (previously 0.70); pollen pop radius 54 at 0.8x seed power; bee sting 1.15x, linked pass 0.8x and third-visit sweep 1.0x. The original safe reactive pilot remains unchanged; forced catch-seeking was rejected because it drove into hazards. Nine targeted repeats of the weak stage/build groups passed after tuning. Full release validation reruns both characters without targeted filters.

## v0.11.0-test — character mastery
Scout starts unlocked; Poppy requires an actual Stage 3 clear. Existing clear records qualify; existing character selection is safely reset to Scout only if ineligible. No campaign progress is removed. Five cosmetic mastery ranks per character: first clear, 750 bugs, 150 Scout ricochet hits / 40 Poppy roll-catches, three distinct compatibility bonuses used in winning runs, three distinct clears including Stage 5+. All objectives accumulate simultaneously on completed or failed runs; abandonment earns nothing. Only wins count toward clear/bonus goals. Rank titles display in character selection and result screens. Legacy saves start mastery at zero because they do not store per-character combat events.
Skin concepts only (not yet playable): Clover Ranger Scout and Rainy-Day Poppy, proposed reward at mastery rank 4. Built-in image generation used Poppy and Scout atlases as reference. Prompt: preserve identities, soft painted storybook shading, warm brown outlines, matte garden fabrics; Scout moss canvas jacket, clover badge, blue headband and slingshot; Poppy butter-yellow raincoat, sage rain hat, terracotta boots and boomerang. Concept image outside shipped assets at outputs/Mastery-Skin-Concepts.png. Future characters should target subsequent three-stage milestones (6, 9, etc.) once implemented, not fake locked roster slots now.
